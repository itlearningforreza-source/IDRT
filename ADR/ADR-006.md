# ADR-006: Financial Precision: Integer (Wei) Internal, Decimal Display

**Status:** Accepted
**Date:** 2026-11-18
**Deciders:** Principal Architect, Senior Blockchain Engineer, Financial Systems Architect
**Technical Story:** ADR-006

## Context

Python services use float for monetary calculations (e.g., balance / 10**18). Float has 53-bit precision - insufficient for 18-decimal wei values. Causes rounding errors in dashboards, alerts, reconciliation.

## Decision

All internal financial calculations use Python int (wei, 18 decimals). Use Decimal ONLY for display/formatting with explicit conversion functions: wei_to_decimal(wei) and decimal_to_wei(Decimal). Reserve ratio calculated as basis points (10000 = 100%) using integer arithmetic: (fiat_wei * 10000) // supply_wei. Database stores NUMERIC(78,0) for wei values. Never use float in financial code paths.

## Consequences

### Positive
- Zero rounding errors
- Deterministic calculations
- Audit-friendly
- Matches on-chain precision

### Negative
- Developer discipline required
- Conversion functions needed
- Decimal for display only
