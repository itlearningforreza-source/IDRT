# ADR-001: Use OpenZeppelin AccessControl vs Custom Implementation

**Status:** Accepted
**Date:** 2026-11-18
**Deciders:** Principal Architect, Senior Blockchain Engineer, Financial Systems Architect
**Technical Story:** ADR-001

## Context

The codebase contains a custom 123-line AccessControl.sol implementation that replicates OpenZeppelin's AccessControl. This introduces unaudited code in the critical authorization path, misses key features (getRoleMember, getRoleMemberCount, AccessControlDefaultAdminRules), and creates tooling incompatibility.

## Decision

Replace contracts/access/AccessControl.sol with import from @openzeppelin/contracts/access/AccessControl.sol. Update all contracts inheriting from custom AccessControl to inherit from OZ version. Remove custom file entirely.

## Consequences

### Positive
- Battle-tested, audited code
- Full feature parity
- Tooling compatibility
- Community support
- Easier audits

### Negative
- Migration effort (1 day)
- Need to verify role hierarchy matches
- Storage layout unchanged (inheritance only)
