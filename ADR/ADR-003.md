# ADR-003: Bridge Architecture: Lock-Mint via LayerZero

**Status:** Proposed
**Date:** 2026-11-18
**Deciders:** Principal Architect, Senior Blockchain Engineer, Financial Systems Architect
**Technical Story:** ADR-003

## Context

Current bridge uses single relayer key with no verification, no finality handling, no rate limits. This is a CRITICAL security vulnerability. A production bridge must be trust-minimized with cryptographic verification.

## Decision

Integrate LayerZero v2 for cross-chain messaging. Replace BridgeVault/BridgeRelayer with LayerZero OApp pattern: User calls send() on source → LayerZero DVN verifies → Executor calls receive() on destination → Tokens minted. Retain lock-mint model (burn on source, mint on destination) for accounting clarity. Configure DVN (Decentralized Verifier Network) with 3+ verifiers. Add rate limits per chain. Implement circuit breaker on anomaly.

## Consequences

### Positive
- Decentralized verification
- Proven security model
- Finality handling built-in
- Rate limiting
- Multi-chain support

### Negative
- Dependency on LayerZero
- Gas cost for verification
- Complexity of OApp pattern
- Migration from current bridge

## Alternatives Considered
- Axelar (similar model, different network)
- Wormhole (guardian network)
- Custom MPC bridge (high effort, full control)
- Native bridge (if chains support, e.g., Ethereum↔Polygon PoS)
